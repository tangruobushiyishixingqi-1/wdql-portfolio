SMART STAMP PROCESSOR

印章处理器

上传一张照片，提取线稿、编辑点阵，再发送到印章设备。

使用说明
  1. 选择或拍摄一张照片，网页会裁剪为正方形。
  2. 调整提取模式、线宽和输出尺寸。
  3. 生成后可点击预览格子编辑，再下载或打印。
